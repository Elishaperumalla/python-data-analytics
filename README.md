This repository contains practical projects built using **Python, Pandas, NumPy, Matplotlib, and Excel/OpenPyXL**, covering different real-world datasets and analytical problems.

Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-data-analytics.git
```

Move into the project:

```bash
cd python-data-analytics
```

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

---

Running a Project

Navigate to the required project folder:

```bash
cd ecommerce-data-analysis
```

Run the Python script:

```bash
python main.py
```

---

Main Python Libraries

```text
pandas
numpy
matplotlib
openpyxl
```

Install them individually if required:

```bash
pip install pandas numpy matplotlib openpyxl
```
